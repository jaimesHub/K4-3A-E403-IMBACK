# Hướng dẫn in PDF từ file HTML slide

## Bước 1: Mở file bằng trình duyệt
Mở file `CP5-slides.html` bằng trình duyệt (Chrome, Safari, Firefox, Edge).

## Bước 2: Mở hộp thoại Print
Nhấn **Ctrl+P** (Windows/Linux) hoặc **Cmd+P** (macOS).

## Bước 3: Cấu hình in
- **Định dạng giấy:** A4 landscape (ngang)
- **Lề:** Bỏ lề trống (mỗi slide chiếm trọn 1 trang)
- **Header/Footer:** **Bỏ chọn** "Header and footer" / "In header và footer"
- **Background graphics:** **Bật ON** (để khối nền và đường kẻ hiển thị)

## Bước 4: Lưu PDF
Chọn **"Save as PDF"** thay vì in ra máy in, lưu với tên **`demo-slides.pdf`** ở **gốc repo** (cùng cấp với `spec.md`, `REPORT_CP4.md`, v.v.).

## Kiểm tra kết quả
- PDF phải có đúng **6 trang**
- Mỗi trang là 1 slide, khổ A4 landscape
- Chữ đủ lớn, tiêu đề rõ, quote dễ đọc
- Footer mỗi slide: số trang + tên nhóm (I'M BACK · Lớp 3A · Phòng E403)
- Tất cả quote và số liệu phải khớp draft
